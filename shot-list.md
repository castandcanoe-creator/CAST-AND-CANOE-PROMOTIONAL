# Cast & Canoe — Shot List (Screenshots & Clips)

**Status: PRIVATE PREP. Captured material is for the press kit, socials, and video thumbnails — nothing is posted yet.**

## How to use this list

- Canoe captures; Brooke catalogues and edits. Brooke cannot play the game, so raw capture is Canoe's job.
- For every shot: grab **3 versions** (before / during / after) — the middle one is rarely the best.
- Screenshots: native resolution, UI on for feature shots, UI minimal/hidden for beauty shots if the game allows.
- Clips: 10–40 seconds each, no cuts, let the moment finish. Record a vertical-friendly framing in mind for water/character shots (centre the action so a 9:16 crop works).
- Name files: `lake_subject_##` (e.g. `kettle_wave-hello_01.png`, `bayou_boudin_clip_01.mp4`).

**Key:** PK = press kit · SOC = social posts · TH = video thumbnail · VID = short-form/long-form video b-roll
